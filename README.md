# 😈 Shelbinhos FC

Projeto fictício desenvolvido para praticar HTML, CSS e JavaScript, inspirado no nosso clube Shelbinhos FC.

O site possui uma identidade visual escura, com preto e tons de ouro velho, além de páginas para loja, elenco, carrinho e highlights.

## ⚽ Funcionalidades

- Página inicial do clube
- Loja com os uniformes oficiais
- Elenco com fotos dos jogadores
- Carrinho de compras
- Controle de quantidade dos produtos
- Cálculo automático do valor total
- Carrinho salvo com LocalStorage
- Página de highlights com vídeo
- Layout responsivo

## 👕 Produtos

Atualmente a loja possui:

- Uniforme 1 — Preto
- Uniforme 2 — Branco
